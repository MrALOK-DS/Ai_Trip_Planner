 # ✈️ MyTrip AI Planner

**MyTrip AI Planner** ek modern full-stack web application hai jo users ke budget, origin, destination, headcount aur travel style ke hisaab se automated, day-wise AI itineraries generate karta hai.

---

## 🌟 Key Features

* **🤖 Smart Day-Wise Itinerary Generation:** Morning, Afternoon, aur Evening time-slots ke sath tailored travel plans.
* **📍 Origin to Destination Search:** Full address autocomplete and location selection for departure and arrival.
* **🗺️ Interactive Google Maps Route & Distance:** Real-time distance matrix, route polyline visualization, aur direct navigation links.
* **💰 Headcount & Reverse-Budget Engine:** Single traveler se lekar large groups (2–30 people) ke liye per-person aur total budget calculation.
* **📊 Itemized Expense Breakdown:** Detailed spending report (Train/Flight/Bus, Hotel Stays, Food, Activities, aur Emergency Buffer).
* **🚆 Multi-Modal Transit & Stay Recommendations:** Verified direct booking options for Trains (IRCTC/ConfirmTkt), Flights (Skyscanner/Google Flights), Buses (RedBus), and Stays (Luxury to ₹300–₹500/night ultra-budget dorms).
* **🎯 Customizable Travel Styles:** Pre-defined tags (Spiritual, Adventure, Foodie, Romantic) + Custom user preferences input.
* **📄 Offline PDF Guide Download:** Complete itinerary aur financial summary ko 1-click me PDF format me export karne ka feature.
* **🏛️ Java OOP Architecture Showcase:** Clean implementation of Abstraction, Inheritance, Polymorphism, and Encapsulation.

---

## 🛠️ Tech Stack

* **Backend:** Java, Spring Boot, REST APIs, Maven
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+), Dynamic UI Components
* **Mapping & Location Services:** Google Maps JavaScript API, Directions API, Distance Matrix API, Google Places Autocomplete
* **AI Engine:** Gemini AI / OpenAI API Integration
* **Document Export:** iText / OpenPDF / Client-side PDF Generator
